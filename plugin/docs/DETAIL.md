# 人脸分组 · 详细说明

把一堆照片里出现的**每一张不同的脸**认出来，同一个人归成一组，未命名的人自动编号
`person_001`、`person_002`……，另外把「多人合照」和「没有人脸」的单列。全程在本机推理，
照片不出这台机器。

## 它做什么

1. **扫描**：递归读取你指定的文件夹里的图片。常规格式 jpg/jpeg/png/webp/bmp/tif/tiff/heic/heif；
   相机 RAW 支持 raf（富士）、arw/srf/sr2（索尼）、cr2/cr3/crw（佳能）、nef/nrw（尼康）、
   dng、orf（奥林巴斯）、rw2/rwl（松下）、pef（宾得）、srw（三星）、3fr/fff（哈苏）、
   iiq、mrw、kdc、dcr、x3f（适马）等，靠 libraw 解码，优先用相机内嵌的 JPEG 预览（约 1920px，
   毫秒级），没有预览时才做半尺寸去马赛克。
2. **检测**：SCRFD（`det_10g.onnx`）找出每张脸的位置和五个关键点。
3. **对齐**：按 ArcFace 五点到 112×112 的相似变换裁剪，摆正。
4. **取特征**：ArcFace（`w600k_r50.onnx`）输出 512 维向量，同一人向量接近、不同人远离。
5. **聚类**：以余弦相似度阈值（默认 0.42）贪心聚类，质量高的脸先当种子，同一人的脸吸附上去。
6. **出报告**：每个组给出代表图、成员缩略图、相似度；导出时可把每组复制进独立文件夹。

## 第一次使用：准备运行环境

插件只管界面与调度，真正的推理靠本机 python。首次打开面板时，如果缺少运行环境，顶部会出现「运行环境还没准备好」的卡片，点 **准备运行环境** 即可全自动完成：

1. 在 `~/.dsh-face-sorter/.venv` 建虚拟环境（有 uv 用 uv 取 python 3.11；没有则用系统 python 3.10+）。
2. 安装 `onnxruntime`、`numpy`、`opencv-python-headless`、`pillow`、`pillow-heif`、`rawpy`。默认走官方 PyPI，失败自动退到 aliyun 镜像。
3. 从 ModelScope 下载 `det_10g.onnx` 与 `w600k_r50.onnx`（约 190MB，带百分比进度）。
4. 用 onnxruntime 实际加载两个模型做校验，通过后才报告就绪。

过程可取消；已完成的步骤不会重做（再次点击是秒级幂等检查）。运行环境处于 `~/.dsh-face-sorter`，与插件安装目录分离，升级插件不会丢。历史上放在工作区 `Documents/deepseek-harness/default-workspace/face-sorter` 的环境会被自动沿用。

## 面板怎么用

- 左侧栏点「人脸分组」进入面板。
- 顶部「相册文件夹」填本地路径（如 `/Users/你/Pictures/2023`），或用「选择…」按钮。
- 点「开始扫描」。进度条会显示已处理张数；随时可以「停止」。
- 扫描完左列是组列表：`person_001`、`person_002`……以及「多人合照」「无人脸」。
  点某一组，右侧显示该组的代表图和所有成员缩略图。
- **相似度阈值**滑杆可当场重算（不会重新跑模型，只是在已有向量上重新聚类）：
  调低会把更多人并成一组，调高会拆得更细。
- 组名可改（例如把 `person_001` 改成「妈妈」）；改名只影响显示与导出目录名。
- 「导出到文件夹」把每组图片**复制**到目标目录下的一组子文件夹里。默认不搬动原文件。

## 以图找人

- 先扫描一个文件夹，让插件把参照图库里的人脸特征建起来（`faces.json`）。
- 在「以图找人」卡片里把某个人的照片拖进去（可多张，支持 JPG/PNG/HEIC 与主流 RAW），或点击选择文件。
- 插件会检测这些照片里的人脸、提取特征，再和参照图库逐脸比对：
  相似度超过阈值的照片按「身份」分组列出，同一张查询照片里有几个人就分几组。
- 每组上方是查询人脸（你放进去的那几张），下方是命中照片；会标注主要来自哪个原有分组，
  例如「person_001 命中 31/50」，方便你判断是否要放宽/收紧阈值。
- 每组的「导出这一组」和顶部的「导出全部命中」都是**复制**原图到目标目录，不改动原始文件。

只用 CPU：一张查询照片从检测到比对约 1 秒，与参照图库大小无关（比对是向量点积）。

## 给 AI 用的工具

插件注册了两个工具，助手可以直接调用、不用你手点面板。

`face_group_scan` —— 扫描一个文件夹并聚类：

- `folder`：要扫描的目录（绝对路径或 `~/…`，递归扫描）
- `threshold`：相似度阈值，默认 0.42；调高拆得更细，调低合并得更多

返回每组的人数、成员样例与运行 id；缩略图在面板里看。

`face_find_person` —— 在已扫描的图库里找出某个人：

- `photos`：一或多张这个人的参照照片路径（每张人脸算一个查询）
- `refFolder` / `refRunId`：用哪个扫描结果当图库（不填用最近一次）
- `threshold`：默认 0.35，偏招回；要更严格就往 0.45 调
- `exportTo`：可选，给出目录则把命中的图按身份复制进去

它会先用 `face_group_scan` 建立过图库为前提；返回身份数、命中张数，
以及每组主要来自哪个原有分组（例如 `person_001 28/50`）。

## 设置

设置面板可改 python 路径、模型目录、检测阈值、最小人脸、长边缩放、缩略图尺寸。
默认值指向工作区 `face-sorter/` 下的 `.venv` 与 `models/buffalo_l`；这两样由
`setup.sh` 生成（幂等，可重复执行）。运行产物（`data/runs/`）也留在工作区里，方便清理。

## 精度与边界

- **同一个人不同年龄/角度/光线**：相似度会掉。0.42 适合「同一个人近几年」的照片；
  跨十几年或妆造差异很大时，可把阈值降到 0.35 左右，代价是不同人可能被并在一起。
- **侧脸、遮挡、过小人脸**：低于 `minFace` 的脸直接忽略；侧脸特征不稳，容易单独成组，
  可以把阈值调低一点合并。
- **多人合照**：每张脸都参与聚类，所以同一张照片可能出现在多个组里；同时它也会在
  「多人合照」里出现一次，方便你专门检查这类图。
- **没人脸**：风景、文档、屏幕截图统一归到「无人脸」。
- **性能**：CPU 单线程推理，约 1 秒/张（1600px 长边）。RAW 有内嵌预览时额外开销可忽略；
  没有预览的机身会走去马赛克，约 1–2 秒/张。几千张照片建议先缩小 `maxSide`。

## 隐私

模型和照片都只在本机；worker 只把缩略图和特征向量写进工作区 `data/runs/<job>/`，
不联网、不上传。工作区里的 `data/` 可以定期删掉。
