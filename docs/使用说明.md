# 人脸分组插件 · 使用说明

从零开始：装 DSH → 装插件 → 准备运行环境 → 批量分组 → 以图找人 → 导出。

所有推理都在你自己的电脑上完成，照片不会上传到任何地方。

---

## 1. 先装好 DSH

DSH（DeepSeek Harness）是这套插件运行的底座。没装过的话先装它。

**系统要求**

| 平台 | 支持情况 |
| --- | --- |
| macOS（Apple 芯片 M 系列，13+） | 支持，本插件已验证 |
| Linux | 理论上可用，未逐一验证 |
| Windows | DSH 本体支持，但本插件的环境准备脚本**尚未适配 Windows**（路径为 macOS/Linux 形态），暂不建议 |

**下载地址**

- 官网：<https://www.deepseek.com/harness/>
- macOS（Apple 芯片）：<https://download.deepseek.com/desktop/dsh-latest-macos-arm64.dmg>
- Windows x64（仅装 DSH 可用，跑本插件暂不行）：<https://download.deepseek.com/desktop/dsh-latest-windows-x64.exe>

**macOS 安装步骤**

1. 双击下载的 `.dmg`，把「DeepSeek Harness」拖进「应用程序」。
2. 第一次打开如果提示「无法验证开发者」：打开「系统设置 → 隐私与安全性」，在底部点「仍然打开」。
3. 首次启动按引导完成登录 / 密钥配置，进入主界面（一个会话语界面 + 左侧栏）。

装好后你应该能看到左侧栏里有「插件」「技能」「记忆系统」这些入口。本说明后面提到的操作都在这个界面里。

## 2. 装插件

三种方式，按你手上的东西挑一个。装完都要**重启一次 DSH**，左侧栏才会出现「人脸分组」。

### 方式 A：别人给了你一个本地安装包（最省事）

对方给你的应该是 `dsh-face-sorter-x.y.z-local.zip`（约 176MB，里面已经带了人脸模型）。

```bash
# 1. 解压
unzip dsh-face-sorter-0.2.1-local.zip
cd dsh-face-sorter-0.2.1-local

# 2. 把预置模型放进运行时目录（省掉 190MB 下载）
./install.sh
```

3. 把这个目录装成插件：打开 DSH「插件」页，在安装框里填**这个目录的绝对路径**；
   或者直接在任意对话里说「把 /你的路径/dsh-face-sorter-0.2.1-local 装成插件」，让 AI 帮你调 `plugin_manager`。
4. 重启 DSH。

### 方式 B：填安装码（需要能访问 GitHub）

「插件」页安装框里填：

```
github:skyskrr-0627/dsh-face-sorter
```

首次安装要 clone 仓库，约 3–5 分钟。装完重启 DSH。

### 方式 C：从插件市场的索引源装

DSH 的插件市场（Discover）没有官方总索引，只显示你手动添加的索引源。

1. 进「插件」页 → Discover → **Add index source**，填：

   ```
   https://gh-proxy.com/https://raw.githubusercontent.com/skyskrr-0627/dsh-face-sorter/main/market/index.json
   ```

   访问不了就换：`https://gcore.jsdelivr.net/gh/skyskrr-0627/dsh-face-sorter@main/market/index.json`

2. 搜「人脸分组」→ 安装 → 重启 DSH。

## 3. 第一次运行：准备运行环境

插件本身不含 python 环境和模型，第一次用要准备一次。

1. 左侧栏点「人脸分组」（如果没看到，说明还没重启 DSH）。
2. 面板顶部如果有橙色卡片「**运行环境还没准备好**」，点「**准备运行环境**」。
3. 等它自己跑完，会依次做四件事（卡片上有百分比和日志）：

   | 步骤 | 说明 |
   | --- | --- |
   | 建虚拟环境 | 优先用你电脑上已有的 python 3.10+；没有才让 uv 下载一个 python 3.11（约 26MB） |
   | 装依赖 | onnxruntime / opencv / pillow / pillow-heif / rawpy，约 60MB，默认走国内镜像 |
   | 下载模型 | `det_10g.onnx` + `w600k_r50.onnx`，约 190MB（**用本地安装包已经预置，这一步会跳过**） |
   | 校验 | 用 onnxruntime 真正加载两个模型，通过才报就绪 |

4. 就绪后卡片消失，面板顶部会显示 `python 就绪`、`模型就绪` 两个绿色标记。

准备过程中可以点「取消」；已经完成的步骤不会重做，下次点按钮是秒级的幂等检查。

环境放在 `~/.dsh-face-sorter`，和插件安装目录分开，升级插件不会丢。

## 4. 批量分组：把同一个人的照片归到一起

1. **照片文件夹**：填一个目录的绝对路径，或点「选择文件夹」用系统选择框。
   会递归扫描子目录。
2. **相似阈值**：默认 `0.30`，先不用动（后面调）。
3. 点「**开始分析**」。底部会显示进度：`处理中…` → `分析中…`，大库（几百上千张）通常每张 1 秒左右。
4. 完成后上方出现统计条：

   ```
   738 图片   527 含人脸   1314 人脸   182 分组   211 无人脸   262s 用时   0.30 阈值
   ```

5. 下面的卡片网格就是结果：每张卡片是一个「身份」（`person_001`、`person_002`…），
   卡片上写着「N 张图片 · M 张人脸」，封面是这个身份里质量最好的一张脸，
   点「展开全部 N 张」可以看全部成员缩略图。

### 阈值怎么调

阈值是**同一人的判定线**，调大更严（同一个人的照片可能被拆成两组），调小更松（不同人可能被并成一组）。

拖动滑块会就地重新分组，不用重新分析（几秒内重排），试几次就有手感：

| 场景 | 建议阈值 |
| --- | --- |
| 想看清到底有几个人、怕混进别人 | 0.40 – 0.50 |
| 一般整理（默认） | 0.30 |
| 一个人跨越很多年 / 戴眼镜 / 妆容差异大，想都收进来 | 0.55 – 0.65 |

实际参考：同一个人的不同照片相似度普遍在 0.8 以上，不同人大多在 0.2 以下；0.3 附近是明显的分界带（实测某库 182 个身份、1314 张脸）。

### 特殊情况的归类

- **多人合照**：一张照片里有多张脸时，会分别出现在对应身份的成员列表里（一张照片可以属于多个身份）。
- **没人脸的照片**：统计里的「无人脸」数量，不进入任何分组。
- **未命名的身份**：插件不认识人，只按人脸聚类，所以叫 `person_001` 这样。想改成真名，目前没有改名入口（可以记下来，需要就跟作者提）。

## 5. 以图找人：拿一张照片，在图库里找出这个人的所有照片

前置条件：先对目标图库做过一次扫描（第 4 步），建立参照。

1. 在面板里找到「**以图找人**」区域（在统计条上方）。
2. 把某个人的照片**拖进虚线框**，或点框内任意位置选文件。可以一次拖多张（同一个人不同角度效果更好）。
3. 支持 RAW：`.raf .arw .cr2 .cr3 .nef .nrw .dng .orf .rw2 .pef .srw .3fr .x3f` 等 29 种，HEIC 也行。
4. 上传完成后自动比对，结果按「查询身份」分行显示：

   ```
   命中 31 张图片   1 张查询人脸   1 个身份
   原分组 person_001 31/50
   ```

   `31/50` 表示这个人在参照图库的 `person_001` 里共有 50 张，本次命中 31 张。
5. 每行后面有「导出这一组」「导出全部命中」。

**找人的阈值建议比分组更松一点：0.32 – 0.38**。
实测同一人：阈值 0.30 命中 39/50，0.42 命中 17/50，0.52 只有 5/50 —— 调太严会大量漏掉。

也可以直接让 AI 帮你做：在对话里说「用 这张照片 在 <图库目录> 里找出同一个人并导出到 <目录>」，AI 会调用 `face_find_person` 工具完成。

---

## 6. 导出：只复制，不动原文件

- 「**导出这一组**」：把某个身份的所有照片复制到一个子目录。
- 「**全部导出（N 组）**」：每个身份一个子目录，按 `person_001/`、`person_002/` 分开。
- 「**导出目录**」留空 = 复制到本次运行目录下的 `export/`；也可以填绝对路径，例如 `/Volumes/你的盘/整理结果`。

导出永远是**复制**：原图不会被移动、改名或删除。文件多的库注意磁盘空间。

## 7. 支持的格式与性能

| 类型 | 扩展名 |
| --- | --- |
| 常见图片 | `.jpg .jpeg .png .webp .bmp .tif .tiff` |
| 手机照片 | `.heic .heif` |
| 相机 RAW | `.raf .arw .srf .sr2 .cr2 .cr3 .crw .nef .nrw .dng .orf .rw2 .rwl .raw .pef .srw .3fr .fff .iiq .cap .mrw .kdc .dcr .x3f .erf .mef .mos .pxn .r3d` |

- RAW 优先读相机内嵌的 JPEG 预览（快，0.1 秒级），没有预览才做完整解码（1–2 秒）。
- 缩略图一律用内嵌预览，所以不占额外时间。
- 参考速度：1200–1600px 的 jpg 约 1.1 秒/张（CPU，4 线程）；实测 738 张混合 RAW 库 262 秒。

## 8. 常见问题

**左侧栏没有「人脸分组」**
装完没重启 DSH。完全退出应用（⌘Q）再开。

**卡片一直提示「运行环境还没准备好」**
点卡片上的「准备运行环境」。如果报错，把卡片上的日志末尾几行发给作者。

**面板里 python / 模型 显示红色「缺失」**
同上。若模型显示「未下载」但你有本地包，先跑一次包里的 `./install.sh`。

**缩略图是空白框**
旧版本的问题（浏览器直连图片接口拿不到权限），已在 0.2.0 之后修好。升级插件 + 刷新面板（⌘R）。

**同一个人的照片被拆成好几组**
阈值调低（如 0.30 → 0.25）；或者用「以图找人」直接把这个人一次捞出来。

**不同人被并到一组**
阈值调高（如 0.30 → 0.40）。

**侧脸、遮脸、戴墨镜的照片没识别到**
检测阶段就漏了，阈值调低没用。可以把这类照片单独启一次低阈值扫描（面板暂未暴露该参数，需要的话提需求）。

**扫描很慢**
CPU 推理，速度取决于图片数量和分辨率。先把明显不相干的目录排除掉；导出到外置硬盘也算时间。

**想彻底卸载**
「插件」页卸载插件，再删 `~/.dsh-face-sorter`（含环境和模型，约 250MB）以及扫描结果目录。

## 9. 隐私

- 人脸检测与特征提取全部在本机 onnxruntime 上跑，**不联网、不上传照片**。
- 插件联网只发生在两件事上：装依赖（pip 镜像）、下载模型（ModelScope）；本地安装包连这两步都省了。
- 扫描结果（缩略图、特征向量、报告）存在 `~/.dsh-face-sorter/data` 下，随你删。
- 特征向量是 512 维浮点数组，不是照片；但配合缩略图仍属个人信息，分享结果目录前留意。
